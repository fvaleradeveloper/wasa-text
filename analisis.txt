El equipo es una estación de desarrollo con Windows 10 Pro, Intel i7-8700,
16 GB RAM y GPU NVIDIA GTX 970 (4GB VRAM). Tras realizar limpieza de cachés,
desinstalación de aplicaciones redundantes y reubicación de datos a otros
discos, el disco C: pasó de 18.2 GB libres (8% - CRÍTICO) a 48.6 GB libres
(22% - ACEPTABLE). Se recuperaron más de 30 GB.

El equipo tiene potencial para desarrollo y codificación con IA local
mediante AirLLM (configurado), con soporte para modelos de codificación
DeepSeek-Coder, Qwen3, Llama 3, Mistral y Phi.
(Nota: Kimi K3 no es compatible con la GTX 970 - requiere flash-attn/Ampere+)

Restan por aplicar (requieren permisos de administrador):
  - Mover pagefile.sys de C: a J: (~6.5 GB adicionales)

  - i7-8700 (6 núcleos/12 hilos) + 16 GB RAM: suficiente para compilar y
    ejecutar proyectos Node.js/TypeScript, Docker y servidores locales.
  - GTX 970 (4GB): permite ejecutar modelos de IA de hasta 235B
    parametros localmente via AirLLM (DeepSeek-Coder para codificación).
    (Kimi K3 2.8T NO compatible - requiere flash-attn/GPU Ampere+)

    proyectos, caches y modelos.
  - Automatización semanal configurada para evitar que C: se vuelva a llenar.

ACCIONES PENDIENTES de ejecución manual por el usuario:
  1. Ejecutar J:\Temp\mover_pagefile.bat como administrador y reiniciar
  2. Opcional: powercfg /h off para liberar 6.4 GB (si no usa hibernación)
  3. Reiniciar Docker Desktop para aplicar data-root en J:\DockerData
  4. Opcional: mover MiniConda3 a otro disco (~7.7 GB)
  5. Reinstalar extensiones esenciales de VS Code tras regeneración de config
